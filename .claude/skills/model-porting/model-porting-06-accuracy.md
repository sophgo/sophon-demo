# 步骤 06：精度测试

## 前置

步骤 05 已完成（Python 推理代码可用），测试数据集已就绪。

## 提示词

```
对所有 BModel 运行精度测试：

1. 在 PyTorch 基线上运行测试集，记录基线精度
2. 对每个 BModel（芯片 × 精度 × batch）运行 Python 推理
3. 根据需要选择精度指标：
   - 图像分类：Top-1/Top-5 Accuracy
   - 目标检测：COCO mAP (AP@IoU=0.5:0.95, AP@IoU=0.5)
   - 人脸识别：余弦相似度
   - 语音识别：CER (字符错误率) / WER (词错误率)
   - OCR：字符准确率 / F-score
   - 语义分割：mIoU
   - 超分辨率：PSNR / SSIM
   - 立体匹配：D1 (3-px error rate)
4. 输出精度对比表，按芯片+精度分列
5. 精度异常的标记并给出调整建议
```

## 预期输出

```markdown
| 芯片 | 精度 | Python Acc (%) | PyTorch Acc (%) | Diff | 状态 |

| BM1684X | FP16 | 79.38 | 79.42 | -0.04 | ✅ |

```

## 内联知识：精度判定标准

| 精度类型 | ✅ 正常 | ⚠️ 警告 | 🔴 异常 |
|---------|--------|--------|--------|
| FP32 | diff < 0.1% | diff 0.1~1% | diff > 1% |
| FP16 | diff < 0.5% | diff 0.5~1% | diff > 1% |
| INT8 | diff < 1.5% | diff 1.5~3% | diff > 3% |
| INT8_4b | diff < 3% | diff 3~5% | diff > 5% |

> 注：语音识别等场景标准不同，以模板中设定的目标值为准。

## Debug

| 问题 | 排查方向 |
|------|---------|
| FP32 精度有差异 | 检查预处理参数（mean/std/resize/通道顺序）是否与 PyTorch 一致 |
| FP16 精度下降 | 模型中存在对 FP16 敏感的算子，考虑对该层用 FP32 |
| INT8 精度大幅下降 | 增校准样本数 / 检查校准数据预处理是否与推理一致 / 调大量化阈值 |
| 部分样本异常 | 逐样本对比 logit，定位是预处理还是推理阶段的问题 |
